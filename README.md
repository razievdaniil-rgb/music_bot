# 🎵 Яндекс.Музыка Telegram-бот

Telegram-бот, который парсит страницы Яндекс.Музыки и возвращает информацию о треке: название, исполнителя и длительность.

---

## 📋 Возможности

- Принимает ссылки на треки Яндекс.Музыки
- Извлекает название трека, исполнителя и длительность
- Валидирует входящие ссылки
- Логирует все входящие сообщения
- Обрабатывает ошибки и сообщает о них пользователю

---

## 🛠 Технологии

| Библиотека | Назначение |
|-----------|------------|
| `telegraf` | Telegram Bot Framework |
| `axios` | HTTP-запросы |
| `cheerio` | Парсинг HTML |
| `dotenv` | Управление переменными окружения |

## 📦 Установка

### 1. Клонируй или скачай проект

```bash
git clone <repo-url>
cd yandex-music-bot
```

### 2. Установи зависимости

```bash
npm install
```

---

## ⚙️ Настройка

### 1. Создай файл `.env`

Скопируй пример:

```bash
cp .env.example .env
```

### 2. Получи токен бота

1. Открой Telegram и найди бота **[@BotFather](https://t.me/BotFather)**
2. Отправь команду `/newbot`
3. Следуй инструкциям:
   - Введи имя бота (например: `Яндекс Музыка Бот`)
   - Введи username бота (должен заканчиваться на `bot`, например: `yandex_music_info_bot`)
4. BotFather выдаст тебе токен в формате: `123456789:AABBccDDeeFF...`

### 3. Вставь токен в `.env`

```env
BOT_TOKEN=123456789:AABBccDDeeFF...
```

---

## 💬 Использование

1. Найди своего бота в Telegram по username
2. Нажми `/start` или отправь команду `/start`
3. Бот покажет инструкцию
4. Отправь ссылку на трек:

```
https://music.yandex.ru/album/12345/track/67890
```

5. Получи ответ:

```
🎵 Название: Имя трека
👤 Исполнитель: Имя артиста
⏱ Длительность: 03:45
```

---

## 🌐 Формат поддерживаемых ссылок

| Формат | Пример |
|--------|--------|
| `music.yandex.ru` | `https://music.yandex.ru/album/12345/track/67890` |
| `music.yandex.com` | `https://music.yandex.com/album/12345/track/67890` |

> ⚠️ Ссылки на альбомы, плейлисты и исполнителей **не поддерживаются** — только ссылки на конкретный трек.

## 🛡 Обработка ошибок

| Ситуация | Реакция бота |
|----------|-------------|
| Некорректная ссылка | Сообщение об ошибке с примером правильной ссылки |
| Недоступная страница | Понятное сообщение с описанием причины |
| Данные не найдены | Сообщение с объяснением проблемы |
| Пустое сообщение | Просьба отправить ссылку |

---

## 📝 Примечания

- Бот использует только **публично доступные страницы** Яндекс.Музыки
- Никакие платные API не используются
- Парсинг может перестать работать при изменении структуры страниц Яндекс.Музыки
